# 分步教学设计与逐课审校

## 问题与目标

旧版把概念图当作第一步，默认读者已知道 token、shape、FLOPs 等符号；“需要一句解释”被折叠。图示、变式例子与正式题之间也会跳级。此次按学习者指定的解释粒度重新组织全部 18 课：从已有经验出发，先解释术语、用途和小数值计算，再操作图示。

这是一套针对本课程读者的教学设计，不声称 UI 测试能证明所有人的学习效果。

## 阅读顺序与粒度

- 每课有前课衔接、生活比方、三项对应关系，以及比方的适用边界。
- “逐步理解”一次呈现一个知识点。按需逐行展示算例，避免一开始铺满整章。
- 每个知识点有局部判断题，错误反馈解释运算或语义；可展开计算再试，不强制答对才能阅读。
- 运算补充覆盖乘法与 shape、指数、exp、平方根、向上取整、比例、min/max、平均数。关键定义直接出现在讲解中，补充入口用于忘记基础时就地回顾。
- 其后才是已有概念图、明确的观察任务、换条件推演和本课判断。判断可回到精确的小步推导，也可展开原章对应段落。
- 目录支持复习者跳读；返回上一环节保留当前小步位置。小步答题不是正式验收，也不自动勾选完成。
- 完整正文、实验、下载、笔记、备份及离线页面继续保留；不改变课程 ID 与进度结构。

## 逐课检查表

| 课 | 比方 / 起点 | 展开顺序与核对重点 | 图示与判断所需基础 |
| --- | --- | --- | --- |
| Tensor | 共用配方处理多杯饮品 | 模型/引擎 → token/Embedding → shape → 一列乘加 → 多列输出 → FLOPs → B/T/D → 权重存储 | 2MKN 是常用近似计数；输入行数与权重份数不同；[B,T,D] 的最后一维变化 |
| Attention | 查资料的问题、标签、内容 | Q/K/V → 点积 → head → √d → exp → 比例 → V → mask → 减最大值 → 位置 → 90° 示例 → RoPE 链路 | 缩放、屏蔽、归一化职责分别说明；负分数不等于负权重；90° 仅为示例 |
| KV Cache | 留下资料卡避免重复整理 | Prefill/Decode 时点 → 各层 KV → 单 token 元素数 → 字节/单位 → GQA | 已预测与已处理位置不同；128 KiB/token、8192 token=1 GiB；Hkv 减半主体减半 |
| Metrics | 首道菜、菜间隔、餐厅吞吐 | 计时起点 → 4 token/3 间隔 → 公共窗口吞吐 → 尾部 → 并发/到达率 | TPOT 分母 N−1；单 token 不适用；chunk 与 token 边界不能混用 |
| Roofline | 运料与加工同时进行 | 总量/速率 → 单位换算 → max 下界 → 算术强度 → batch 复用 | max 假设充分重叠；理论下界非实测预测；dtype/稀疏条件匹配 |
| Profiling | 下单成功不等于出餐 | kernel/异步 → 计时同步 → 工具层级 → 观察与假设 → 预热/对照 | CPU 返回与设备完成分开；同步会扰动执行；关键路径而非区间盲目求和 |
| Request path | 收单、排单、备料、加工 | 运行身份 → 请求状态 → Scheduler/Runner/KV → 路径命中 → 取消回收 | 谁掌握进度、谁组织张量；静态命中不等于运行证据 |
| Scheduling | 大打印单穿插小单 | 预算 → 动态 batch → 首次 decode 算式 → 长 prefill 16 轮/15 次穿插 → 开销与饥饿 | 42.36/3.96 ms 与 41.36/62.36 ms 的边界不同；线性教学成本不冒充实测 |
| Paged KV | 16 件一箱，33 件拿 3 箱 | 逻辑/物理块 → ceil → 字节差额 → 共享所有权 → 资源不足 | 48 槽与 15 空槽；块表顺序；不能按文本相似性共享；chunk≠block |
| GPU memory | 1000 份作业按 256 编号分组 | 零起始索引 → thread/warp/block/SM → ceil → mask → 存储/stride → tile/寄存器/occupancy | program 不等同线程；1000..1023 共 24 无效位置；大块不保证快 |
| Softmax | 虚构获奖者污染分母 | 稳定计算 → 补齐 → 填 0 的实际分母 → −∞ 与读写保护 → 融合 → 容差/测试 | 有效输出和约 0.213 vs 1；只写 mask 不能修复错误分母；特殊值支持有边界 |
| Attention kernels | 炒菜只占整桌耗时一部分 | T² → 分块分母错误 → m/l/z 合并算例 → 量化 → 100 ms 收益 → Amdahl 公式 | 在线统计使用相同指数参考；局部快 2 倍、整体约 1.053 倍；量化有误差及转换成本 |
| Parallel | 各接客户或分算一张表 | DP → 单卡结果 → 输出列切 → 输入维切 → collective/rank → 通信与 PP | [5,11] 分别由拼接和对应求和恢复；下一层布局决定是否立即收集 |
| MoE | 分诊窗口与最忙窗口 | 总量/激活量 → 单 token 加权 → 分配数 → EP → 平均与尾部 → 均衡成本 | 100×top-2=200 分配，不是用户数；400/175≈2.29；输出归属与数量同样重要 |
| Speculation | 助手起草、目标审核 | 连续前缀 → 成本 → 条件概率连乘 → 期望 → 等量工作加速 → sampling 区别 | E=3.3616 的额外 token 假设；D/V 不免费；接受率不足以证明收益；不能只抄接受公式 |
| Hypothesis | 分段记录通勤再改变一项 | 可测问题 → 观察/解释/方案 → 反证 → 3% 与波动 → 交错 A/B → 提案边界 | 缓存、输出与环境混杂；不挑最好一轮；事前确定验收 |
| Patch | 库存、承诺与限购同时约束 | 四变量 → min → cap=0 语义 → 不变量 → 引擎接入 → 集成与回退 | 504 与 128；不忘 decode 预留；局部函数测试不等于真实引擎正确 |
| Capstone | 能复做的菜谱 | 环境复现 → 收益百分比 → 代价百分比 → 预设门槛 → 机制/覆盖 → 交付 | 37.5%、25%、4% 不能混成整体提速；原门槛 1.4 s 不允许事后偷偷移动 |

## 数学与题目审校约定

1. 先小数值，再字母；公式每个新符号和单位均在同课或明确前课解释。
2. 按现实用途解释运算：总量÷速率求时间、部分÷总和求占比、ceil 求足够多的组、min 满足多重上限、max 表达最慢约束。
3. 变式题必须给足条件，不能用“这两个”指向一个已被隐藏或被用户拖动改变的数值。
4. `quizStep` 指向能解释正式热身题的具体小步，增删步骤时同步检查。
5. 教学比方标出边界；模拟、虚构数字和未执行 GPU 实验不得写成生产结论。
6. 较高级的模型/引擎实现随版本变化，正文中的官方原始资料与固定 commit 阅读要求继续适用。

## 验证范围

`teaching.spec.ts` 遍历全部课程和全部小步：默认从比方开始、逐行算例、数学补充、错答/正答反馈、精确回看、键盘和 375px 宽度。原有回归继续检查完整正文、实验、笔记、进度导入合并、跨窗口同步及单文件离线。

这些测试证明界面与内容连接正确，不能自动证明讲解在教学上充分。上表记录逐课人工审校的主题与边界，后续应根据真实学习反馈继续改进。
