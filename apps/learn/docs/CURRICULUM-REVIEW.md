# 阅读、题目与课程依赖审校

审校日期：2026-09-30。范围为 18 课正文、页面自测、动手练习、验收和下载文件。逐课阅读后人工检查教学关系；自动测试只检查链接、交互和数值，不将测试通过等同于学习效果。

## 判断与修改

保留六阶段顺序。先建立模型前向计算，再学测量和定位；引擎章节只要求建立职责/资源地图；GPU 与分布式章节解释执行机制；最终三课才要求形成完整引擎改动。无需先把 CUDA 或模型训练全部学完。

发现并修复：

- 第二课提前要求解释第三课的增量缓存：改为先验证 causal mask，下一课再解释缓存等价性。
- 第一课的“上面三个张量”指代含糊：明确 X/W/Y；同 FLOPs 练习改为固定 B×T 的两组形状。
- 第七课练习提到 rg 但正文没有命令：补充搜索命令、运行位置和名称随版本变化的说明。
- 第八、九课过早要求改策略、完成回归：基础任务改为观测、设计与手工状态推演，真实集成留到第十七课。
- 第三阶段成果写成策略 patch，与最终阶段边界重叠：改成请求职责与缓存生命周期地图。
- 部分术语先用后讲：补 HBM、kernel、rank、stream、IPC、collective、SLO、stride、contiguous、幂等、microbatch、MTP、exp 等就地解释。
- Online Softmax 只有递推公式：补初始化、全 mask 边界和最大值改变时的 10/3 手算例子。
- MoE “每专家平均 25”缺少专家数：补充 8 专家前提。
- Occupancy 定义过于泛化：限定为 SM 活跃 warp 比例，并附 NVIDIA 官方定义来源。
- 毕业课“不要只统计成功请求”容易被理解成必须为失败记录伪造延迟：改为允许报告成功子集，但必须同步呈现失败/超时。
- 7 道较弱选择题改成计算或情境判断，解释错误选项的具体原因；18 道题均指定正文小节，可从反馈返回讲解。
- 原先仅提示上一课：改为各课实际前置知识列表，所有依赖都指向更早的课。
- 无 GPU 时如何学习不清楚：明确阅读与实验验收分开，未完成实验保持未验收，不阻挡后续阅读。
