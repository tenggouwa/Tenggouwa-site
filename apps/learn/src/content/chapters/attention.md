### 上一课留下的问题：信息怎样跨 token 流动

我们已经知道，每个 token 是一个向量，Linear 可以改变这个向量的特征维度。但如果每个位置都独立计算，“小王把书递给小李，他笑了”中的最后一个位置，怎样利用前面的内容？

Attention 提供一种可学习的信息汇总方式：当前位置根据自己的需要，为允许读取的各个位置分配权重，然后汇总那些位置携带的信息。它不是字符串搜索，也不是从数据库选出一条记录。本课会用一个可手算的例子，把“相关性”和“读取内容”分开。

先沿用 T 表示 token 数、D 表示隐藏维度；新增 d 表示单个注意力头的向量维度。先理解一个 head，多头只是之后的扩展。

### 为什么要有 Q、K、V 三份表示

对输入 X 做三个不同的 Linear，得到 Q、K、V：`Q=XWq`、`K=XWk`、`V=XWv`。它们来自同一批 token，但投影权重不同，因此表达的数值特征不同。

Q 是 query，用来计算当前位置需要读哪里；K 是 key，与 Q 计算匹配分数；V 是 value，是最终被加权汇总的内容。可以借用“提出问题、被匹配的标签、可读取的内容”来理解三者的职责，但不要以为每个维度都有清楚的人类语义。

为什么不直接用同一个向量做三件事？不同投影允许模型分别学习“如何匹配”和“匹配后读什么”。对于我们接下来要做的缓存，K/V 属于历史可复用内容，而新的位置每次有自己的新 Q，这种分工也很重要。

### 手算一次 Attention

设一个 query 为 `[1,0]`，两个 key 为 `[1,0]` 和 `[0,1]`。点积就是对应位置相乘再相加，所以匹配分数是 `[1,0]`。

接着除以 `√d`。这里 d=2，缩放后约为 `[0.707,0]`。为什么缩放？在常见的分量尺度假设下，点积的波动会随维度增加；缩放有助于防止分数随着 d 增长而过大，使 Softmax 过度集中。它不是保证所有模型数值稳定的万能规则，而是标准 scaled dot-product attention 的组成部分。

Softmax 把分数转为权重：每项先求 exp（以自然常数 e 为底的指数函数，写作 e 的 x 次方），再除以整行 exp 的总和。`exp(0.707)≈2.028`，`exp(0)=1`，因此两个权重约为 `[0.670,0.330]`，和为 1。

如果两个 value 是 `[2,0]` 和 `[0,4]`，输出就是：

```text
0.670 × [2,0] + 0.330 × [0,4]
≈ [1.340, 1.320]
```

你应该注意到，输出不是某个 token ID，也不是概率表，而是一个新的向量。Softmax 的权重只用来决定怎么混合 V；真正选下一个 token 要等整个模型输出 logits 后再做。

### 把单个 query 扩展到整段输入

假设有 T=4 个 token，每个 Q/K/V 向量长度都是 d=2。Q 和 K 的形状都是 `[4,2]`，`Q @ K.T` 得到 `[4,4]`。第 i 行表示位置 i 对所有位置的匹配，第 j 列表示读位置 j 的分数。

对每一行做 Softmax 后，仍是 `[4,4]`；再乘 `[4,2]` 的 V，得到 `[4,2]`。整条形状链是：

```text
Q [T,d] × Kᵀ [d,T] → scores [T,T]
逐行 Softmax         → weights [T,T]
weights [T,T] × V    → output [T,d]
```

这也解释了标准全注意力为什么随序列长度增长得很快：位置之间的组合数约为 T²。这个结论针对概念上的配对数量；高效实现不一定在 HBM 中真正保存一个完整 `[T,T]` 中间矩阵，后面会讨论 FlashAttention。

### Causal mask：输入并行，不代表允许看未来

在自回归模型中，位置 i 的输出用于预测它后面的 token。如果它在计算时读取了未来输入，训练与推理的条件就不一致。Causal mask 规定位置 i 只能读位置 `0..i`。

对于四个位置，可读关系如下，1 表示可读，0 表示禁止：

```text
位置0: 1 0 0 0
位置1: 1 1 0 0
位置2: 1 1 1 0
位置3: 1 1 1 1
```

禁止的位置在 Softmax 前设为 `-∞`，因为 `exp(-∞)=0`。不要把分数直接设成 0：`exp(0)=1`，它仍会分到权重！也不要先 Softmax 再随意清零而不重新归一化，那会改变结果。

Prefill 虽然一次处理整段输入，也遵守这个 mask。并行计算的是多个合法位置的工作，不是取消因果约束。

### 数值稳定与一个最小实现

若某行分数是 `[1000,999]`，直接计算 exp 可能溢出。先减去该行最大值，变成 `[0,-1]`，归一化的数学结果不变，因为共同的 `exp(-1000)` 因子会在分子分母中约掉。

下面用 PyTorch 写出单头、单序列、无 dropout 的参考实现。它刻意直接展开每一步，便于看清含义；它不是高性能 kernel。

```python
import math
import torch

torch.manual_seed(7)
q, k, v = [torch.randn(4, 2) for _ in range(3)]
scores = q @ k.T / math.sqrt(q.shape[-1])
future = torch.ones(4, 4, dtype=torch.bool).triu(1)
scores = scores.masked_fill(future, -torch.inf)
weights = torch.softmax(scores, dim=-1)
out = weights @ v
assert tuple(out.shape) == (4, 2)
assert torch.allclose(weights.sum(-1), torch.ones(4))
assert weights[0, 1:].count_nonzero() == 0
```

逐行解释：`triu(1)` 只选主对角线以上的位置；`dim=-1` 沿每行的 key 维度归一化；第一个 query 只有自己的位置可读，所以后面三项必须为零。如果你改错 mask，程序仍然可能输出正常浮点数，因此“没有报错”不等于正确。

### 多头、RoPE 和一个完整 block

Multi-head attention 让不同组投影形成多个 head，每个 head 独立做注意力，再把输出拼接并投影回隐藏维度。多头提供不同的学习空间，但不保证某个 head 永远对应某种语言功能。

只有内容匹配还不够，模型还需要位置信息。RoPE 对 Q/K 中成对的分量按位置旋转，使相对位置可以影响匹配。最重要的工程含义是：增量推理时，新 token 的位置必须接着历史位置增长，不能每次都从 0 开始。

典型 block 还包含 Norm、残差连接和 MLP。RMSNorm 根据向量均方尺度调整数值；残差把原输入加回分支输出；MLP 对每个位置做非线性特征变换。常见 pre-norm 结构可概念化为“归一化 → Attention → 残差 → 归一化 → MLP → 残差”，但模型实现会有变化，读源码要看实际结构。

### 停下来检验一次理解

如果把两个 key 的匹配分数同时加上 100，权重应该变吗？不变，因为 Softmax 对整行加同一个常数不敏感。如果只把第一个分数增加，第一项权重通常会增加。

如果将未来位置的 V 改为一个很大的数，前面位置的输出应该变吗？不应该；若变了，优先检查 causal mask。课程附带的 CPU 参考脚本就包含这个因果性检查。本课先看 `full_attention` 和 `causal_error`；脚本同时输出的缓存对比结果，可以留到下一课再解释，不要求现在读懂 `cached_attention`。

现在你已经能解释 Q/K/V、分数、mask、权重和输出之间的区别。下一课会问：生成新 token 时，这些工作哪些需要重新做，哪些可以留下来？这就是 KV Cache 的出发点。
